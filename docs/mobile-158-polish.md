## Download preference

The `offline-downloads` preferences store `qualityTier` as LOW/MEDIUM/HIGH. Existing integer `quality` values migrate once: 360/480 → Low, 720 → Medium, 1080/2160 → High. New/invalid preferences default to Medium. Available resolutions are ranked per video using existing discovery extremes and midpoint, rather than fixed thresholds. With two options Medium chooses the lower one; with one option all tiers use it. Explicit picker choices retain priority through progressive discovery and picker dismissal. Batch defaults use each episode's available tier; explicit choices retain existing closest-resolution behavior, source ownership, audio validation, and stream keys. Streaming preferences are separate.
