# Aliflix v3.1.112

Mobile version code 202; based on v3.1.111. TV stays on 3.1.69.

- Recently watched removal now presents the same poster, rounded surface, Cancel, and Delete treatment as downloaded-item removal. Dismissal never mutates history.
- CineJoy is the first default streaming provider, using exact TMDB movie and season/episode routes. A one-time local preference migration makes the setting visible; later source choices remain available. Existing playable resume routes remain the fastest shortcut.
- Opening details resolves and buffers one candidate at a time, with a 30-second total limit. Leaving details or stopping the activity cancels the job and destroys its hidden resolver views. No service, history update, or audible playback is started. Play consumes only a fresh request matching the exact title/episode and resume point, then uses existing native playback recovery.
- The loader is a Compose Canvas port of HMS Loading, recolored in lilac, with no descriptive text. Shared-axis scale/fade motion connects details to playback, and the artwork fades when the first video frame is ready.
- Home artwork and its background now occupy one continuous plane, blended with the same carousel progress. Details uses one continuous backdrop behind the hero and its content.
- Genres follows About; Details follows Trailer.

Validation: mobile and TV Kotlin compilation. User waived automated tests and emulator/device validation. Smoothness, provider availability, and startup timing on a phone remain unverified; preloading reduces work after Play when a usable stream is ready, but cannot guarantee instant starts on every network.
