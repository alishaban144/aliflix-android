# Aliflix v3.1.118

The movie and series "More Info" page now behaves like Home: the poster belongs to the page, occupies
the hero only, and scrolling down scrolls it away to leave the dark Aliflix background underneath.

## The details poster was fixed behind the page

`DetailScreen` drew `CinematicBackdrop` as a sibling of its `LazyColumn`, exactly as Home used to,
so the artwork never moved. The hero could scroll away and the same poster, sharp and defocused, was
still filling the screen behind the About, Episodes and More Like This sections.

There was one extra wrinkle here that Home did not have. The details list is padded down by the
status bar, so the hero's top edge sat one status bar below the top of the screen, while the
stationary plane drew the artwork from the very top. Simply moving the plane into the hero item
would therefore have cropped it at the status bar line and left a hard edge between flat dark and
artwork right under the clock.

## The hero absorbs the inset instead

The status bar padding moved off the list and into the hero item, through the new
`detailHeroFrame(heroTopInset, heroHeight)`. The hero item is now `inset + heroHeight` tall, the
plane fills that frame with `matchParentSize()`, and the existing hero content sits in a box padded
down by the same inset.

Every absolute position is unchanged:

* the plane starts at the top of the screen, behind the status bar, and its frame ends on the same
  line as before, so the crop, the alpha mask and the tint are identical to the stationary plane's;
* the hero content keeps its own coordinates, because the content box is the frame minus the inset;
* every item below the hero starts at `inset + heroHeight` either way, since the list lost exactly
  the padding the hero item gained.

What changes is only what happens on scroll. The plane is a child of the hero item, so it is
translated by the list as the hero is, and the hero item is disposed once it leaves; the sections
below sit on the plain `AliflixBackgroundBase` of the parent box. As on Home, the plane's tint is
already fully opaque at its own lower edge, so the artwork meets the page background on that line
with no seam. The only visual difference at rest is below the hero, which is now simply dark instead
of carrying the leftover ramp of the old full-screen plane.

The back button, the history reminder and the title block were already inside the hero item, so they
scroll away exactly as before. `CinematicPosterPlane` now resolves its band through `posterBand` as
well, so an unbounded or collapsed host draws no artwork rather than an unbounded one.

## Validation

The mobile unit test suite, `lintMobileDebug`, mobile and TV Kotlin compilation and the instrumented
test sources all pass locally, with no new warnings. A new `DetailHeroFrameTest` covers the geometry:
the frame is the hero plus the inset, it collapses to the hero without one, the scrolling plane
crops the same artwork the stationary plane did, and a frame taller than the plane is cut off rather
than inverted.

Unit tests, lint and emulator validation are skipped in this release's workflow run at user request,
and no device run has confirmed the rendered scroll.
