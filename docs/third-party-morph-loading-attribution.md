# Morph Loading

The native Ask loader adapts [Morph Loading by Jatin Yadav](https://21st.dev/@jatin-yadav05/components/morph-loading), published July 27, 2025 on 21st.dev.

The four authored morph paths, timing, stagger, scale and corner changes are retained. The implementation uses Android Compose Canvas, Aliflix colours and a static reduced-motion state. No preview images, video or demo layout are bundled.

Source accessed through the component's official Copy code action; published preview CSS supplied the associated keyframes.
