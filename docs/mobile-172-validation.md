# Mobile 3.1.172 validation

This release fixes the Talk exit failure reproduced on Pixel 7a with published 3.1.170. Android reported `NetworkOnMainThreadException` while TLS `close_notify` was written during connection-pool eviction in `TalkVoiceActivity.onDestroy`. Network disposal now runs on the existing HTTP executor, with idempotent audio/focus teardown and no premature executor shutdown.

Talk automatically requests microphone permission and connects when opened. It retains Gemini 3.8 Live / Aoede, native turn detection, interruption and resumption. Controls are transcript, microphone, end, privacy and close; failures expose Retry without Start/Resume. Moving diffuse orb lighting follows real input/output PCM energy; gaze and blink changes are Talk-specific. Context words are shaped natively and sampled off-main into thousands of fine circular particles. The persistent dot lettering settles from the flow field and carries a restrained moving light; there is no solid-text overlay. A visible feathered corona and rotating conic light surround the orb and react to microphone/assistant PCM. Controls have no bulky center background. Semantic display themes come from the same Live model through a local nonblocking tool, with filler rejection and stable follow-up context rather than streaming token prefixes.

User-owned recent progress is bounded to eight entries with exact season/episode, seconds, duration and strict completion. A cached on-demand viewing tool resolves independent TVMaze/Wikidata identities, retains gaps in viewed episode ranges, and does not request TMDB prose or audio from playback. No extra conversational model or TTS is introduced. Existing history privacy controls remain.

Playback preferences show Auto/Low inline. Download preferences show Auto/Low inline; the existing saved balanced tier remains effective until changed. Source download quality availability and episode pickers retain their behavior.

IMDb results merge partial host responses rather than returning on the first incomplete season. A verified parent plus exact S/E is authoritative across translated titles; explicit episode IMDb IDs still must match. No missing score is invented. TV retains its existing rating and orb behavior.

Design references: [Live Orb](https://23rd.dev/docs/components/live-orb), [Radix Toggle Group](https://www.radix-ui.com/primitives/docs/components/toggle-group), and the existing [Pixel Flow Field reference](https://21st.dev/community/components?preview=%2F%40educalvolpz%2Fcomponents%2Fpixel-flow-field). Native Compose adaptations reuse Aliflix surfaces, motion, accessibility and reduced-motion settings.

Validation results and public artifact evidence are appended after the focused device checks and GitHub workflow finish. Original native/model assets and subtitle synchronization algorithms are unchanged.

Focused evidence so far: local mobile debug/unit/test APK build succeeded; 670 unit tests, zero failures/errors, three opt-in host-native skips. Worker full suite 152 passed, followed by 26 focused Talk tests after identity/cache improvements. On Pixel 7a, all 26 Dark episodes across seasons 1-3 returned their own verified IMDb ID and score in a 1.911-second live repository test, including English season-2 titles matched against original German names.

Final focused Pixel checks passed: automatic listening, two real Gemini Live turns, meaningful `THE SHINING` topic retained after an acknowledgement, pinned Aoede voice, active-session exit returning to the existing MainActivity, and microphone/audio state reset. Test duration 27.934 seconds; measured rendered first-audio delays 1771ms and 1455ms. Separate Talk privacy/transcript/close and inline playback-quality UI checks passed (2 tests, 5.248 seconds). The first lifecycle fixture used ActivityScenario launch/idle synchronization and hung on the animated screen; it was replaced with direct lifecycle observation and rerun successfully. The stopped fixture is not counted as a pass.

The device installation uses the existing private test signer to retain user data. Production signing and original published APK proof remain separate GitHub release gates. Local downloaded subtitles/audio, binary/model bytes and Sync with Audio algorithms were not changed. These focused checks do not establish universal AI accuracy, source uptime or flawless behavior on every device.

External OS screenshots were reviewed at two different animation frames (`mobile-172/talk-first.png`, `talk-second.png`). Hardware Back from an automatically opened conversation returned to MainActivity with the same app process still alive. The screenshots contain no private dialogue.

An authenticated live backend check used synthetic viewing history (Dark S2E1 at 1200 seconds and The Shining as a favorite). It initially exposed TVMaze unavailability; a Wikidata exact-IMDb-ID recovery path was added and deployed. The rerun resolved both correct titles, retained the partial-episode boundary, and returned in 236ms (cached follow-up 65ms). The new tool also re-reads current session state after asynchronous identity lookup and refuses to recreate deleted context; focused regressions cover concurrent quota/grant changes and closing during lookup.

The first publication run was cancelled before APK release when the user requested a stronger visual revision and sticky conversation language. The final candidate replaces solid topic glyphs with fine-dot Canvas lettering, dims the background field, adds a more visible moving corona and removes the center control surface. Response language is established once from the first utterance, retained in local session/resumption context, and changed only by an explicit user request through the same Live model's local language control tool. Old installed clients do not receive unknown tools. Final device/CI results are appended below; earlier screenshots are superseded.

Final language/topic acceptance passed on Pixel in 42.172 seconds: English replies for the first three turns, including the German-language Dark question, then German only for the explicit change request. Topics were THE SHINING / THE SHINING / DARK / DARK; the voice stayed Aoede. Rendered first-audio times were 1450, 1259, 1536 and 1017ms. Silent UI-control acknowledgements use native SILENT scheduling so they do not create extra spoken turns. Actual output transcription was inspected. Active-session exit still returned to the original MainActivity.

The final rendering implementation caches settled dot paths and combines the rotating colour and feathered alpha in one Android ComposeShader pass. The physical rendering fixture (synthetic energy, no microphone or model request) passed with both Latin and Arabic words: 1052 frames, 0 modern jank events, 0 missed vsyncs; UI p50/p90/p95/p99 18/20/20/21ms, GPU 5/6/6/7ms. Earlier full-screen captures predate the final smooth shader and are not final visual proof.

Final focused Talk controls/inline playback-quality tests passed (2 tests, 5.352s); the language/turn-detector JVM suite and 29 backend Talk tests passed. Original native/model parity and final signing/public artifact verification remain the release workflow gates.
