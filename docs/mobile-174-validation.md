The released visual topic depended on an optional Live function call. Its local fallback recognized only a few concepts and refused to change an established subject. The new turn-level fallback recognizes explicit named-title clauses and meaningful themes, and film-knowledge calls independently set the verified requested title. Streaming transcription fragments are not used as arbitrary first-word labels. Follow-ups retain the subject; silent semantic control remains available in Gemini Live. A physical spoken-input test caught an additional false subject, ONE SENTENCE, from an atmosphere follow-up. Formatting-only/filler labels are now rejected, with that exact utterance covered by a JVM regression.

The visual revision keeps the original moving dot field and spherical capsule eyes. A five-second linear conic gradient with a continuous feathered radial falloff replaces the prior stepped-looking corona. Input/output PCM energy controls its brightness and scale independently of rotation. Gaze favors attentive forward focus, brief small speaking glances and smooth return; turn boundaries do not restart the gaze loop. Blinks have varied timing. These changes are opt-in to the Talk orb; Discover/TV defaults retain their behavior. Topic glyphs use larger, rounded Nunito at 42sp (32sp for long labels), sampled into the same fine circular dot paths off-main, with Arabic fallback shaping and reduced motion preserved. Settled geometry remains cached.

Previously My List preceded Favorites and entries without IMDb IDs were excluded. Talk now prioritizes Favorites, retains opaque catalogue identifiers, resolves only external identity from TMDB, and retrieves independent names through TVMaze/Wikidata. Eight-item pages allow on-demand access beyond the bounded initial snapshot. Favorites represent explicit taste; saved intent and actual completed progress remain separate. Recommendations are instructed to read taste first, avoid treating already-loved titles as new discoveries, and vary choices and phrasing. Optional recent-suggestion memory is bounded to 24 titles/seven days and respects Keep history/account ownership/deletion. No persistent suggestion memory is kept without consent.

A new read-only native app-context tool supplies current quality, next-episode, speed, subtitle and audio-boost preferences, library counts, and verified navigation/feature descriptions for Ask, My Space, playback, sources, audio/subtitles, synchronization, downloads, Watch Together and privacy. It cannot mutate settings, control playback or claim live provider observations. The sole conversational engine remains gemini-3.8-live with pinned Aoede and the existing explicit-only language switching, resumption, interruption and audio teardown. Existing Describe/Similar models, playback, synchronization algorithms and native/model binaries are unchanged.

Backend pagination is authenticated, strictly validated, deadline-bound and limited to four concurrent identity/title lookups. Cache keys separate pages; identity cache is bounded. Concurrent quota/grant state is preserved. Both viewing and knowledge results recheck owner/session existence after asynchronous retrieval so deletion cannot resurrect cached context. Legacy clients do not receive tools they cannot handle.

Connection review found an additional missing remote-close acknowledgement: OkHttp onClosed fires after both peers close, while onClosing alone means the server will transmit no more messages. Talk now acknowledges onClosing (normalizing the reserved empty-close sentinel) and immediately enters the existing same-model reconnect flow. A separate 25-second unanswered-turn deadline resets on finalized input progress, clears on actual PCM output or teardown, and exposes the existing concise Retry state if a response stalls. It never switches model/voice or fabricates a spoken fallback. The original timeout's exact upstream cause was not established; these changes address independently verified lifecycle gaps and bound waiting rather than claiming the cloud can never fail. The earlier publication run 39136677238 was cancelled before any APK release to include this recovery change.
